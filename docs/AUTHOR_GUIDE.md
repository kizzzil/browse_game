# Гайд автора: как написать эпизод «Маяка»

Сюжет сезона — в [SERIES.md](SERIES.md), технический формат — в [CONTRACTS.md](CONTRACTS.md).
Здесь — практический порядок работы.

## 1. Где что лежит

| Путь | Что | Публикуется? |
|---|---|---|
| `content/<id>/quest.js` | Исходник эпизода: главы, тексты, подсказки, **ответы открытым текстом** | нет |
| `content/<id>/key.json` | Ключ контента платного эпизода (создаётся сборкой) | нет, секрет |
| `content/codes.json` | Коды доступа: `{ "ep2": [...], "season": [...] }` | нет, секрет |
| `js/platform/catalog.js` | Каталог сезона: название, тизер, цена, `free`, длительность | да |
| `quests/<id>/quest.json` / `.enc.json` | Результат сборки (хэши ответов; платные — зашифрованы) | да |
| `world/social/data/ep<N>.js` | Профили и посты «Ленты» для эпизода N | да |
| `world/<site>/` | Вымышленные сайты эпизода (фонд, реестр, брокер…) | да |
| `world/media/<id>/` | Фото, аудио и прочие файлы эпизода | да |
| `tools/build.js` | Сборка `content → quests → dist/` | нет |

## 2. Порядок работы над эпизодом

1. Добавьте эпизод в `js/platform/catalog.js` (если его там нет).
2. Напишите `content/<id>/quest.js` по формату из CONTRACTS.md. Ответы — массив вариантов
   открытым текстом: регистр, `ё/е`, пробелы и знаки препинания при проверке не важны
   (`"В.С."`, `"вс"` и `"в с"` — одно и то же).
3. Ссылки из глав — относительно `play.html`: `world/social/#vera.somova`,
   `world/fund/reports.html`. Сборка предупредит о ссылке на несуществующий файл.
4. Посты персонажей — в `world/social/data/ep<N>.js` через `World.profile / World.posts / World.bio`.
   Посты эпизода N видны в «Ленте», только когда игрок дошёл до эпизода N
   (движок выставляет `mayak:worldEpisode`). Для главы можно указать `worldEpisode`.
5. Соберите и проверьте:

```bash
node tools/build.js
cd dist && python3 -m http.server 8765
# http://localhost:8765/            — витрина
# http://localhost:8765/play.html#ep2 — эпизод (код MAYAK-DEMO-2026 открывает платные)
```

Перед публикацией прогоните сквозной автотест: `node tools/playtest.js` (должен закончиться
«ОК»). Если добавили главу или поменяли ответ — обновите сценарий в `tools/playtest.js`
и прохождение в `docs/walkthrough/ep<N>.md`.

Чтобы посмотреть «Ленту» глазами игрока поздних эпизодов, в консоли браузера на сайте:
`localStorage.setItem("mayak:worldEpisode", "4")`.

### Необязательные поля квеста

- `previously: ["абзац", …]` — блок «Ранее в сезоне» на стартовом экране эпизода.
- `finale.winTitle`, `finale.loseTitle` — заголовки концовок (по умолчанию «Дело раскрыто.» / «Не тот вывод.»).
- `finale.button` — текст кнопки финала.
- `finale.evidence: [{ id, icon, title, text }]` — улики, которые добавляются на доску при победе.
- Варианты мультивыбора (`finale.multi: true`) могут иметь `icon` и `text` — они покажутся в карточке.

## 3. Правила безопасности (обязательно)

- **Только вымышленные персонажи, компании и сайты.** Никаких реальных аккаунтов, ИНН,
  телефонов, номеров карт. Номер карты на чеке — вымышленный (`tools/receipt.html`).
- Каждый сайт в `world/` в подвале содержит строку
  «Вымышленный сайт для игры «Маяк». Все совпадения случайны.»
- Задания не требуют писать людям, регистрироваться, что-либо взламывать или платить.
  Все улики — в открытом доступе на страницах мира.
- Реальными могут быть только общедоступные географические объекты и общедоступные
  онлайн-инструменты (просмотрщики EXIF, декодеры, карты, спектрограммы).
- Никаких внешних запросов, CDN и шрифтов: всё лежит в репозитории.

## 4. Если захотите вывести персонажей в настоящие соцсети

Можно продублировать посты «Ленты» в реальных соцсетях как аккаунты персонажей игры.
Тогда: создавайте аккаунты сами, помечайте в описании «персонаж игры „Маяк“», не
выдавайте себя за реальных людей, учитывайте правила площадки (вымышленные аккаунты
могут заблокировать — держите «Ленту» как основной источник). Тексты постов и
комментариев берите из `world/social/data/*.js`.

## 5. Хэш ответа вручную

Обычно не нужен: сборка хэширует ответы сама. Для отладки:

```bash
node tools/hash.js --quest ep1 "Северный ветер"
```
