# Дело №0913 — браузерный триллер-квест

Игрок — внештатный аналитик, который расследует исчезновение аудитора Анны Вельской.
Сама игра — это «папка с делом» в браузере, а улики разбросаны **по интернету**:
в профилях персонажей в соцсетях, в комментариях под постами, на сайте вымышленного фонда
и даже в исходном коде его страниц. Игрок находит улику, возвращается и вводит ответ.

## Как запустить

Сборка не нужна, это статический сайт.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно выложить как есть на GitHub Pages, Netlify или любой статический хостинг.

## Как устроено

| Файл | Что внутри |
|---|---|
| `index.html`, `css/style.css`, `js/game.js` | Интерфейс игры: брифинги, документы, ввод ответов, доска улик, финал. Прогресс хранится в `localStorage`. |
| `js/case.js` | **Весь сценарий**: главы, тексты, ссылки, подсказки, улики, хэши ответов. Новое дело = новый такой файл. |
| `js/answers.js` | Нормализация ответа (регистр, `ё→е`, без пробелов и знаков) и проверка по SHA-256. |
| `mock/` | Демо-профили персонажей (похожи на ленту соцсети), чтобы игру можно было пройти без реальных аккаунтов. |
| `fund/` | Сайт вымышленного фонда «Маяк». В `reports.html` спрятана улика в HTML-комментарии. |
| `tools/hash.js`, `tools/hash.html` | Посчитать хэш ответа для `case.js`. |
| `tools/receipt.html` | Генератор чека-реквизита: распечатать и сфотографировать для поста персонажа. |
