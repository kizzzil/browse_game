# «Маяк» — детективный сезон в браузере

Платформа браузерных триллер-квестов. Сезон «Маяк» — четыре связанных дела (первое
бесплатное, остальные платные). Сама игра — «папка с делом», а улики разбросаны **по
интернету персонажей**: вымышленная соцсеть «Лента», сайты компаний, реестр юрлиц,
архивы, фотографии с метаданными, аудио. Игрок находит улику, возвращается и вводит ответ.

Опубликовано: https://kizzzil.github.io/browse_game/

## Запуск и сборка

Нужен только Node 22 (для сборки) и любой статический сервер.

```bash
node tools/build.js                 # content/ → quests/ (хэши, шифрование) → dist/
cd dist && python3 -m http.server 8765
# http://localhost:8765/                — витрина сезона
# http://localhost:8765/play.html#ep1   — эпизод 1
```

Тестовый код доступа к платным эпизодам: `MAYAK-DEMO-2026` (можно и ссылкой:
`index.html?code=MAYAK-DEMO-2026`). Перед реальными продажами его нужно убрать — см.
[docs/PAYMENTS.md](docs/PAYMENTS.md).

Публикуется **только содержимое `dist/`** (на GitHub Pages — из ветки/артефакта со сборкой).
`dist/` в `.gitignore`.

## Структура

```
index.html, css/platform.css      витрина: герой сезона, эпизоды, прогресс, покупка, код доступа
play.html, css/game.css           движок квеста: play.html#<id>
css/access.css                    модалка покупки (общая)
js/core/answers.js                нормализация и SHA-256-проверка ответов
js/core/storage.js                безопасный localStorage, ключи "mayak:*"
js/core/vault.js                  AES-GCM + PBKDF2 (браузер и node)
js/platform/catalog.js            каталог сезона (цены, тизеры, free)
js/platform/access.js             права доступа + адаптер оплаты (demo / свой сервер)
js/platform/home.js               логика витрины
js/engine/game.js                 движок: главы, подсказки, доска улик, финал, блокировка
content/<id>/quest.js             исходники эпизодов (ответы открытым текстом) — не публикуются
content/<id>/key.json, codes.json ключи и коды доступа — не публикуются
quests/<id>/quest(.enc).json      собранные эпизоды (генерирует tools/build.js)
quests/manifest.json              список опубликованных эпизодов
world/social/                     соцсеть «Лента»: world/social/#<ник>
world/fund/, world/registry/, …   вымышленные сайты эпизодов
world/media/<id>/                 медиафайлы эпизодов
tools/build.js, tools/hash.js     сборка и хэш ответа
tools/receipt.html                генератор чека-реквизита
docs/                             SERIES (сюжет), CONTRACTS (форматы), PAYMENTS (оплата), AUTHOR_GUIDE
```

## Как это работает

- **Ответы** хранятся только как SHA-256 от `"<id>:" + нормализованный ответ`.
- **Платные эпизоды** зашифрованы ключом контента K; K открывается кодом доступа или
  (в будущем) выдаётся сервером оплаты. Подробно — [docs/PAYMENTS.md](docs/PAYMENTS.md).
- **Прогресс** — в `localStorage` игрока: `mayak:progress:<id>`, общий позывной
  `mayak:agent`, открытые эпизоды `mayak:keys`, видимость «Ленты» `mayak:worldEpisode`.
- **Мир растёт вместе с сюжетом:** посты эпизода N появляются в «Ленте», когда игрок
  доходит до эпизода N.

Как написать новый эпизод — [docs/AUTHOR_GUIDE.md](docs/AUTHOR_GUIDE.md).
